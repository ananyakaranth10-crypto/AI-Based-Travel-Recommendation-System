# AI-Based Travel Recommendation System

## Overview

The AI-Based Travel Recommendation System is a Flask-based web application that recommends tourist destinations across India based on user preferences.

## Features

- User Registration & Login
- Personalized Travel Recommendations
- Rule-Based Filtering
- Content-Based Filtering
- TF-IDF Vectorization
- Cosine Similarity
- Trip Planner
- Favorites
- Reviews
- Google Maps Integration

## Technologies Used

- Python
- Flask
- HTML
- CSS
- JavaScript
- Bootstrap
- SQLite
- Pandas
- NumPy
- Scikit-learn

## Recommendation Technique

- Rule-Based Filtering
- TF-IDF Vectorization
- Cosine Similarity

## Database

SQLite

```bash
pip install -r requirements.txt
